# 快递代取工作台（v1）

这是一个无需后端的手机端原型：将腾讯文档导出为 **CSV** 后上传，系统会按“收件人姓名 + 手机尾号”将订单自动归组，方便一个人的快递放进同一个收纳框。

## 使用方法

1. 双击 `index.html`，或用任意本地静态服务器打开它。
2. 在腾讯文档中导出 Excel（XLSX/XLS）或 CSV；表格应包含：`收件人姓名`、`收件人电话`、`驿站选择`、`取件码`（`订单截图`、`填写时间`可选）。
3. 点击「导入表格」。

页面初次打开不包含任何订单。导入后会直接采用表格中 `驿站选择` 列的实际内容生成筛选项。

仓库只包含网页源代码，不包含演示订单、腾讯文档、导出表格或真实订单。

## 已实现

- 手机优先布局；待取件、已取件两页
- 按人员分组、展示同框件数与每人的领取进度
- 驿站筛选、超大取件码、复制取件码、订单截图页内弹窗预览
- 单件标记已取；已取件状态锁定，避免误触改回；状态仅保存在该设备浏览器
- Excel / CSV 自动识别，即使文件扩展名错误也会根据内容判断格式
- 自动定位表头并映射腾讯文档当前字段

## 关于“订单截图”

只读取表格的 `订单截图（必填）` 列（括号内说明可变化）。该列包含有效的 HTTP/HTTPS 链接时，卡片才会显示“打开订单截图”；缺少该列、单元格为空或内容不是有效链接时，明确显示“无订单截图”，不会生成虚假图片或二维码。腾讯文档的分享链接能否打开取决于访问者是否拥有相应权限。

## 腾讯文档授权同步（v2）

本地导入没有平台费用；腾讯文档直连通常要开发者应用、OAuth 授权和接口权限（具体可用性取决于腾讯文档/企业微信的接口开放范围），成本主要是开发与后端部署。生产使用还应增加员工登录、服务端数据库、图片私有存储和短期留存策略。
